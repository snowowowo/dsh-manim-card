## 一张卡片长什么样

在会话中提出「用 Manim 绘制一个定积分」，卡片随即出现在聊天流里：

![聊天流中的 Manim 动画卡片：标题行、画布，右侧三个按钮](./shots/card-preview.png)

卡片顶栏是标题与三个按钮——播放、查看代码、导出视频。播放完停在终态画面，不会自己重来。

## 装上

1. 按[安装](/guide/installation)把插件装进 DeepSeek Harness 桌面版；
2. 刷新宿主页面；
3. 在会话里说「用 Manim 画一个单位圆」。
