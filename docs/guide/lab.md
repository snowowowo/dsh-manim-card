# 实验场

实验场在左侧导航的「Manim 渲染」页面，用于语料回归与自由编写代码。本页讲它的界面、工具条、通过判定、进度保存与语料文件的位置。

## 界面

左侧为语料清单，右侧为渲染预览：点击任一条即运行，「全部渲染」按顺序执行，通过 / 失败状态即时标注在条目上。实验场不是独立实现的调试页——**画布与聊天卡片使用同一组件**，因此手动播放、查看代码、导出等能力与聊天内完全一致。

页面顶部提供两种视图：**语料实验场**与**自定义代码**（自由编写并运行一段 Python）。

## 工具条

- **全部渲染**：仅运行尚未通过的条目，已通过的跳过；分组标题旁的按钮仅运行该组。
- **停止** / **复制结果** / **清除记录**。
- **极速**：不等待 `run_time` 与 `wait`，直接落至终态。批量渲染 236 条按真实时间需数分钟，极速模式可即时完成；需要观察动画过程时关闭该开关。

## 通过 / 失败的判定

每条语料自带预期（悬停可见）。「通过」并非「运行完成且未报错」——**标注「应当被拒绝」的语料，运行失败才算通过**（其验证的正是「当场拒绝且能说明原因」）。红绿点、「通过 N 条」计数、续跑均依据此判据。

「复制结果」会包含每条的结果、报错与**所在文件路径**，依据该输出可直接定位到对应的 `.py` 文件。

## 进度保存

逐条结果、极速开关、自定义代码、当前视图均存入 localStorage，刷新或中断后可从断点继续。

## 语料的位置

语料本体是核心包 manim-live 仓 `_dev/examples/` 下的完整 Manim 文件（19 组 / 236 条），可独立运行：

```bash
manim ../manim-live/_dev/examples/basic/01-circle.py CircleScene
```

正式安装中该目录不存在，实验场自动退化为「自定义代码」视图——语料是开发期的回归用例集，不随插件发布。
