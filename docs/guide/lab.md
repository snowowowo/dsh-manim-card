# 实验场

实验场在左侧导航的「Manim 渲染」页面，是**本插件功能的验收台**：卡片渲染、播放控制、查看代码、导出 mp4、预检报错，都在这里对照着验。本页讲它的界面、样例模式、自定义代码与进度保存。

样例是**内置**的一小集（打进插件，正式安装里同样可用）；239 条那套语料回归网由核心包 [manim-live](https://github.com/snowowowo/manim-live) 仓承担（`corpus/`），本插件不维护语料。

## 界面

左侧为样例清单，右侧为渲染预览：点击任一条即渲染，通过 / 未通过状态即时标注在条目上。实验场不是独立实现的调试页——**画布与聊天卡片使用同一组件**，因此手动播放、查看代码、导出等能力与聊天内完全一致。

页面顶部提供两种模式：**样例**与**自定义代码**（自由编写并运行一段 Python）。

## 环境状态条

页头下方常驻一条环境读数，四枚 chip：**本机 Manim**（导出 mp4 走它）、**运行时**、**公式样式**、**浏览器能力**。这四组条件决定「能不能出画面、能不能导出 mp4」。

- 满足的条件是中性色标签；不满足的各自上色（黄 = 要注意，红 = 错）并且可以点开。
- 点开是同一块面板：这台机器上所有待处理的条件逐条列出（浏览器侧那几句由核心包给出，本机侧写明缺哪几项），下面是能立刻做的动作——**立即预热**（把运行时先拉起来；第一次渲染要等约 13 MB 下载完，预热掉的是这段等待）与**重新检测**（再问一次本机环境）。
- 运行时「未加载」与公式样式「未配置」都不是错误，只是「还没有」：前者点预热即可，后者要在创建渲染器时传 `katexBaseURL`。
- 读数随状态变化自动刷新：浏览器侧（运行时阶段、取包结果、公式样式加载结果）变化即刷新；本机侧在进入页面时问一次、按「重新检测」再问一次（Host 侧带缓存，几十张卡同时问也只跑一遍探测）。

## 样例模式

样例集约十条，覆盖基础图形、变换、坐标系与曲线、MathTex 公式、文字列表、柱状图、TracedPath 轨迹、3D 场景，以及**一条应当被预检拒绝的坏代码**。

- 每条样例左侧有状态点：未跑（空心）/ 通过（绿）/ 未通过（红）。
- 点中一条后，预览上方显示该样例的**预期**（一句话「应该看到什么」）——人工验收对着它看。
- 通过判定：普通样例渲染成功即通过；标注「应当被拒绝」的那条**反过来**——渲染失败才算通过，它验的正是「预检当场报错并说明原因」。

## 工具条

- **停止** / **清除记录**。
- **极速**：不等待 `run_time` 与 `wait`，直接落至终态。切换开关会把当前条按新口径重跑一遍；updater 驱动的轨迹仍会被推进，不会变成空的。
- **清除已下载的库**：把本机缓存的第三方包删掉，用于重验「首次取包」的过程。

## 进度保存

逐条结果、极速开关、自定义代码、当前模式均存入 localStorage，刷新或中断后可从断点继续。
