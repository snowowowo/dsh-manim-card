# 实验场

左侧导航「Manim 渲染」那一页是**实验场**：左边语料清单、右边渲染预览，点哪条跑哪条，也可以「全部渲染」按顺序跑完，通过 / 失败当场标在条目上。它不是一个另做的调试页——**画布就是聊天卡片那个组件**，所以手动播放 / 查看代码 / 导出这些能力天然一致。

页面顶部有视图切换：**语料实验场** 与 **自定义代码**（自由写一段 Python 跑）。

## 工具条

- **全部渲染**：只跑尚未通过的，已通过的跳过；分组标题旁的按钮只跑这一组。
- **停止** / **复制结果** / **清除记录**。
- **极速**：不等 `run_time` 与 `wait`，直接落到终态——批量渲染 236 条按真实时间要几分钟，极速下一屏就完事。看动画过程时关掉它。

## 通过 / 失败按「预期」判

每条语料自带预期（悬停可见）。「通过」不是「跑完不炸」——**标了「应当被拒绝」的语料，跑不通才是通过**（它验的就是「当场拒掉、且说得清」）。红绿点、「通过 N 条」、续跑都走这一个判据。

「复制结果」把每条的结果、报错与**所在文件路径**一起带走，拿这份回执就能直接定位到那一个 `.py` 文件。

## 进度不丢

逐条结果、极速开关、自定义代码、当前视图都存 localStorage，刷新或中途崩了不用从头再来。

## 语料在哪

语料本体是核心包 `manim-live` 仓里 `_dev/examples/` 下的完整 Manim 文件（19 组 / 236 条），独立可跑：

```bash
manim ../manim-live/_dev/examples/basic/01-circle.py CircleScene
```

正式安装里这个目录不存在，实验场自然退化成「自定义代码」——语料是开发期的回归网，不随插件发布。
