# 它是什么

本页定位 dsh-manim-card：它给宿主加了什么、与原生 Manim 差在哪、链路上的三方各管什么、与核心包 `manim-live` 的边界在哪。装好就用请看[安装](/guide/installation)与[在聊天里用](/guide/usage)。

## 一句话定位

dsh-manim-card 是 DeepSeek Harness（下称「宿主」）的插件：AI 在会话里写**标准 Manim（Python）代码**，聊天流中当场出现可播放、可查看代码、可导出视频的动画卡片。

## 它给宿主加了什么

| 落点 | 内容 | 详情 |
| --- | --- | --- |
| 聊天流 | 动画卡片：AI 调用 `manim_card` 后出现，支持手动播放、查看代码、导出视频 | [在聊天里用](/guide/usage) |
| 工具 | `manim_card`：工具返回前在 Node 侧的真解释器里干跑一遍，语法错、未定义名、不支持的写法当场以 `error` 回给模型 | [宿主工具](/api/tool) |
| 设置面板 | 「Manim Card」一节：浏览器运行时（含逐帧导出能力）、包缓存管理 | [设置面板](/guide/settings) |

插件内部的播放调度值得单独一句：新卡片首次入视口完整播放一次、重新挂载落末帧、活跃画布超过 8 张时按距阅读位置由远及近回收、全页共享一条 Python 执行队列。规则逐条列在[在聊天里用](/guide/usage#自动播放规则)。

## 与原生 Manim 的差别

代码是同一份标准 Manim Python，差别只在「在哪里执行、如何产出画面」：

| | 原生 Manim（命令行） | 本插件 |
| --- | --- | --- |
| 写的代码 | 标准 Manim Python | 同一份代码，原样可跑 |
| 执行环境 | 本机装 Python + manim + ffmpeg（公式还要 LaTeX） | 浏览器内的 Pyodide，零本机安装 |
| 出画面方式 | 离线渲染成 mp4，播放与嵌入需另行解决 | 聊天流内实时渲染，即写即演 |
| 与讲解的配合 | 单次渲染需等整条管线跑完 | 进入视口即播放；预检先把有问题的代码拦在渲染之前 |
| 导出视频 | 命令行产出 mp4 | 在同一块画布上逐帧编码成视频文件，产物落「下载」文件夹；本机不用装 manim 或 ffmpeg |
| 部署成本 | 每台机器装一遍环境，或架渲染服务器 | 装一个插件；运行资源随包分发，不依赖外网 CDN |

可用面是 Manim CE 的常用子集，覆盖范围与缺失项以核心包[支持面](https://snowowowo.github.io/manim-live/guide/support)为准。

## 三方分工

从「AI 写代码」到「聊天里看到动画」，链路上有三方，各管一段：

| 参与方 | 负责 | 不负责 |
| --- | --- | --- |
| 宿主 | 会话与聊天流、槽位与服务体系、`manim_card` 的调用与日志 | 渲染、Manim 语法、导出 |
| 核心包 [manim-live](https://snowowowo.github.io/manim-live/) | 浏览器内的 Python 执行、manim 适配层、WebGL 画布、环境状态判定、逐帧导出 | 宿主接入、卡片界面、资源路由 |
| 本插件 | 宿主接入（路由、工具、槽位）、卡片与播放调度、设置面板、导出接线 | 渲染与执行本身 |

接口按使用者分成两条对外面：给模型的是 [`manim_card` 工具](/api/tool)，给人用的是聊天卡片。本插件**不导出可供 `import` 的 JavaScript 模块**，也**不对外提供 Cordis 服务**——没有别的插件需要消费它；要在自己的项目里用同一块画布，直接依赖核心包。

## 与核心包 manim-live 的关系

[manim-live](https://github.com/snowowowo/manim-live)（[文档站](https://snowowowo.github.io/manim-live/)）是独立的 npm 包，执行与渲染的核心能力都在它那里；本插件是它在宿主里的接入层——装本插件即带上它（构建时内联进 `client.js`），**不必另行安装**。按场景选择：

| 想要 | 用什么 |
| --- | --- |
| 在宿主会话里让 AI 画动画、看卡片、导出视频 | 本插件 |
| 在自己的页面或产品里嵌一块同样的画布，脱离宿主 | 核心包 manim-live |
| 在自己的插件里用一块同样的画布与运行时 | 核心包 manim-live（它不认宿主，也不认哪个插件在用） |
| 对一份语料做批量回归 | 核心包仓的 `corpus/`；本插件不维护语料——条数与覆盖以那边为准 |

## 不适用

- **服务器端批量渲染视频**：用 manim 命令行原生管线。本插件的预检依赖宿主 Node 侧运行时，导出在浏览器里逐帧进行，都不面向批量产出。
- **脱离宿主的独立产品**：直接依赖核心包 manim-live。
- **Manim 全量能力**：以核心包支持面为准。

## 从哪开始

- 装上并跑出第一张卡片 → [安装](/guide/installation)、[在聊天里用](/guide/usage)
- 检查这台机器的条件（能不能出画面、能不能导出） → [设置面板](/guide/settings)
- 在自己的插件里用画布 → 核心包 [manim-live 的文档](https://snowowowo.github.io/manim-live/)；本插件自己的接口见 [API 参考](/api/)
