# 在聊天里用

## 卡片怎么长出来

会话里对 AI 说「用 Manim 画……」，AI 会调 `manim_render` 工具提交一段 Python。工具**返回前先干跑预检**——语法错、未定义名、写法不支持当场回 `error`，所以卡片出现的时机，代码已经是能跑的。渲染成功后卡片停在终态画面；失败则在卡片底部给出 manim 的原话。

## 自动播的规则

聊天流里可能同时有很多张卡，全部真播一遍既吵又慢，所以只有一类卡真播：

- **「刚生成的那张」正常播一遍**——它第一次进视口时播放。
- 之后任何一次重挂载（切会话回来、刷新页面、滚出再滚回）**一律极速落末帧**，不重演。
- 老会话里的卡根本不播，直接出终态画面。
- **同一个 step 里 AI 并行发的好几张，只真播最后一张**——用户等的是结果，不是接连演完的几段动画。
- 滚出视口**不拆**画布；只有活跃画布超过 8 张时，离阅读位置最远的才被收掉（浏览器 WebGL 上下文有上限）。

::: warning 播到一半被打断也算播过了
播放机会「决定即记账」：进了队列又滚出视口、或播到一半按了跳过——机会都用掉了，回来看到的是末帧，不会从头再演。这是刻意的：否则「一滚动它又演一遍」。
:::

## 手动播放

卡片顶栏的播放键有两种形态：没在播时是 ▶（**一定真播**，压过上面全部自动规则），正在播时变成 ⏩（**直接落终态**）。被中断的卡（回合被停止）默认不自动渲染，按 ▶ 手动渲染。

## 导出 mp4

卡片头部有下载键：把这段源码交给**本机装的 manim 命令行**真渲染一遍，mp4 落到「下载」文件夹。

- **按钮亮不亮只看环境**：本机要有 `python3` / `manim` / manim 库 / `ffmpeg`。缺什么，悬停提示会列出来；LaTeX / dvisvgm 只有公式写法才用得到，不算必要条件。
- 导出成功后悬浮出「在文件夹中显示」，点击在系统文件浏览器里定位该文件。
- 导出记录持久保存（卡片随页面刷新重挂后，仍显示「上次导出的文件」；文件被删了也会如实说）。
- 本机需要装什么、怎么查，见[设置面板](/guide/settings)。
