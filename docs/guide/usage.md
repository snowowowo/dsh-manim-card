# 在聊天里用

## 卡片的产生

在会话中向 AI 提出「用 Manim 绘制……」，AI 通过 `manim_render` 工具提交一段 Python 代码。工具返回前会先执行干跑预检：语法错误、未定义名称、不支持的写法会立即以 `error` 返回，因此卡片出现时代码均已通过预检。渲染成功后卡片停留在终态画面；失败时卡片底部显示 manim 的原始错误信息。

## 自动播放规则

聊天流中可能同时存在多张卡片，全部完整播放开销较大，因此仅以下情形完整播放：

- **新生成的卡片**在第一次进入视口时完整播放一次。
- 之后的任何重新挂载（切回会话、刷新页面、滚出后再滚回）一律直接落至末帧，不再重演。
- 历史会话中的卡片不播放，直接显示终态画面。
- 同一 step 内 AI 并行产生的多张卡片，仅完整播放最后一张。
- 卡片滚出视口不销毁画布；活跃画布超过 8 张时，按距阅读位置由远及近回收（浏览器 WebGL 上下文数量存在上限）。

::: warning 播放机会只消耗一次
播放机会在决定时即记录：进入播放队列后滚出视口、或播放中途跳过，机会均已消耗，再次查看时显示的是末帧，不会从头重播。此设计用于避免滚动导致重复播放。
:::

## 手动播放

卡片顶栏的播放按钮有两种状态：未播放时为 ▶（完整播放，优先于上述全部自动规则）；播放中为 ⏩（直接落至终态）。被中断的卡片（回合被停止）默认不自动渲染，需按 ▶ 手动渲染。

## 查看代码

卡片上可直接查看该段 Python 源码，可复制给 AI 继续调整。

## 导出 mp4

卡片头部的下载按钮将该段源码交给本机安装的 manim 命令行真实渲染，mp4 保存至「下载」文件夹。

- **按钮可用性取决于本机环境**：需要 `python3` / `manim` / manim 库 / `ffmpeg`，缺失项会在悬停提示中列出；LaTeX / dvisvgm 仅公式写法需要，不属于必要条件。
- 导出成功后悬浮显示「在文件夹中显示」，点击可在系统文件管理器中定位该文件。
- 导出记录持久保存：页面刷新后卡片仍显示「上次导出的文件」，文件被删除时也会如实显示。
- 本机需要安装什么、如何检查，见[设置面板](/guide/settings)。
