# 在聊天里用

在会话中提出要求（例如「用 Manim 画一个单位圆」），AI 调用 `manim_card` 工具提交一段 Manim Python 代码，卡片随即出现在聊天流中。代码返回前会先跑一遍预检：语法错误、未定义名称、不支持的写法当场回给模型，由模型在同一回合修正。

## 播放规则

聊天流中可能同时存在多张卡片，全部完整播放开销较大，因此只在以下情形完整播放：

| 情形 | 行为 |
| --- | --- |
| 新生成的卡片首次进入视口 | 完整播放一次 |
| 之后的重新挂载（切回会话、刷新页面、滚出去再滚回来） | 直接落至末帧，不重演 |
| 历史会话中的卡片 | 不播放，直接显示终态画面 |
| 同一步骤内并行产生的多张卡片 | 只完整播放最后一张 |
| 滚出视口 | 保留画布；活跃画布超过 8 张时，按距阅读位置由远及近回收 |

::: warning 播放机会只消耗一次
进入播放队列后滚出视口、或播放中途跳过，机会均已消耗，再次查看时显示末帧，不会从头重播。
:::

## 手动播放

卡片顶栏的按钮有两种状态：

- **▶**：完整播放。优先于上述全部自动规则。
- **⏩**：直接落至终态。

被中断的卡片（回合被停止）默认不渲染，按 ▶ 开始。同一页面的所有画布共用一条执行队列，画面不会同时播放。

## 查看代码

卡片上可直接查看该段 Python 源码，复制出来交给 AI 继续调整。

## 画面出不来时

渲染失败时，卡片底部显示 manim 的原始错误信息。如果环境里确有未满足的硬性条件，卡片会再补一行可执行的处置说明——与设置面板的「浏览器运行时」读的是同一份判定。逐项状态见[设置面板](/guide/settings#浏览器运行时)。
