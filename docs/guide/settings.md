# 设置面板

宿主设置里的「Manim 渲染」一节回答两件以后会越来越要紧的事：**「导出」要靠本机真的 Manim**，而**离线可用性取决于哪些包已经在本地**。

## 本机环境

逐项探测 `python3` / `manim` / manim 模块 / `ffmpeg` / `latex` / `dvisvgm`，每项给出 **ok / 缺失 / 出错** 三态。每行是「名字 + ⓘ + 状态点与版本」——「为什么在意它、找到哪儿了、实际跑的命令」全收进 ⓘ（悬浮 / 键盘聚焦才出现）。头部有「重新检测」。

- 探测**用户点开才跑**，逐项串行、各有超时，不是启动时偷偷扫一遍机器。
- 探测自己补齐 PATH（桌面端宿主拿到的 PATH 是被裁剪过的，`/usr/local/bin` 这类常常不在里面）——否则会「装了却说没装」。
- 「manim 库」那项跟着 manim 命令找解释器：命令是软链进某个 venv 的，问 PATH 上第一个 `python3` 必然误报。

## 包缓存

列出常用的十一个库（numpy / sympy / mpmath / matplotlib / pandas / scipy / scikit-learn / statsmodels / networkx / pillow / opencv-python），每行是「状态点 + 名字 + 本机占用 + 一个文字键」：

- 绿实心 = 已缓存，灰实心 = 随包内置，空心环 = 还没缓存；
- 没缓存的给「**缓存**」键（连依赖一起取）；已缓存的给「**删除**」；随包自带的给「内置」（禁用键）。

用词是「缓存」不是「下载」——这些包本来就是运行时按需联网取的（首次 `import pandas` 自动取一次，sha256 校验后落进 `~/.dsh/cache/manim-live/pyodide/`），这里做的是**提前存到本机**，跟「之后断网也能用」是同一件事。

清单下面还有一张**「缓存其他库」**卡片：写上任意包名就能取（`Pillow`、`scikit_learn` 各种写法都认，输入时给补全虚影），取过的手输包会留在清单里——「取回来了、想再清掉」在同一条路径上闭环。
