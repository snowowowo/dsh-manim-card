# 设置面板

设置里的「Manim卡片」一节有两块：浏览器运行时与本机库清单。

| 分组 / 卡片 | 回答的问题 |
| --- | --- |
| 环境 → 浏览器运行时 | 这一页能不能出画面、能不能导出视频 |
| Python 库 | 哪些三方库已经缓存在本机 |

## 浏览器运行时

运行时本身与四项浏览器条件收在一张卡片里，数据取自当前页面。

| 行 | 取值 | 说明 |
| --- | --- | --- |
| Python 运行时 | 未加载 / 加载中 / 就绪 / 失败 | 「未加载」是正常初始状态——首次渲染前需要先取运行资源 |
| 公式样式 | 未配置 / 加载中 / 已加载 / 失败 | 公式排版所需的样式表状态 |
| WebGL | 可用 / 不可用 | 画面本身的出口，没有它渲染不出任何东西 |
| WebAssembly | 可用 / 不可用 | Python 解释器的运行基础 |
| 浏览器导出 | 可用 / 不可用 | 有它才能导出视频（WebCodecs 或 MediaRecorder），缺它只影响导出 |

卡片头部给出待处理项计数；有未满足项时，卡片底部逐条列出可执行的处置。

## Python 库

列出常用的十一个库（numpy / sympy / mpmath / matplotlib / pandas / scipy / scikit-learn / statsmodels / networkx / pillow / opencv-python），每行给出状态、本机占用与一个操作键：

| 状态 | 含义 | 操作 |
| --- | --- | --- |
| 已缓存 | 已缓存在本机 | 删除 |
| 内置 | 随包自带 | 无 |
| 未缓存 | 尚未缓存 | 缓存 |

这些库在运行时按需联网取用，取到后存入 `~/.dsh/cache/manim-live/pyodide/`。此处的「缓存」是提前取回本机，保证之后断网可用；「删除」把它从本机移除，下次用到时再取一次。

清单下方的「缓存其他库」可输入任意包名缓存。
